# Baker Reader

Lector local de PDF, EPUB, CBZ y CBR (RAR4/5) para móviles y tablets Android.

## Anotar

Activa el lápiz y el botón del dedo si no utilizas stylus. Dibuja varios trazos o selecciona un recorte. Mueve la selección desde su interior o ajusta sus esquinas. Pulsa Guardar para previsualizar y añadir una nota. Cancelar conserva el borrador; la X lo descarta.

Las anotaciones se conservan en la app al cerrar y reabrir, sin sobrescribir los documentos originales.

## Obsidian

En Ajustes, vincula la carpeta local del vault con el selector Android. Configura la subcarpeta de destino y guarda los ajustes. Puedes exportar una nota al guardarla, desde el panel de anotaciones o exportar todas las del libro. Incluye imágenes y Markdown. El nombre del vault es opcional para abrir Obsidian.

## Compilar y continuar

Flutter 3.47.2 y Java 17. Ejecuta flutter pub get, flutter analyze, flutter test y flutter build apk --release --split-per-abi. GitHub Actions publica baker-reader-apks.

Consulta [DEVELOPMENT.md](DEVELOPMENT.md) para continuidad desde tablet, pruebas y límites conocidos.
